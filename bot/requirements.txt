#     Python and ships with realtime 2.24.0 (heartbeat bug long fixed).
#
# realtime is pulled transitively by supabase==2.24.0 — we no longer
# need to pin it explicitly. The watchdog in cache.py remains the
# safety net against any residual 1006 WebSocket closures.
